# spider_ai
# 🕷 Spider-AI // Cyber Ollama Chat

Мощный и стильный десктопный AI-чат с кинематографичным интерфейсом, работающий полностью локально на вашем компьютере через **Ollama**. Никаких подписок, никаких цензурных лимитов, полностью бесплатно и конфиденциально!

---

## ⚡ Особенности
- **100% Локально и Бесплатно:** Работает на вашем железе без интернета (после скачивания моделей).
- **Никаких лимитов:** Общайтесь сколько угодно, сервер Ollama обрабатывает запросы без ограничений.
- **Кинематографичный запуск:** Эпичная 2D-анимация с пауком, лазерным прицелом и расколом экрана трещинами.
- **Интерактивный рейтинг моделей:** Модели удобно отсортированы по скорости и интеллекту.
- **Режим «No-Think» (Турбо):** Мгновенный ответ от моделей Qwen и DeepSeek без долгих и скучных простыней «размышлений».
- **Удобный чат:** Карточки сообщений, кнопка быстрого копирования и готовые пресеты промптов.

---

## 🤖 Доступные модели
Приложение поддерживает 5 топовых локальных моделей:
1. ⚡ **`qwen2.5-coder:7b`** — *ТОП-1 по скорости (Молниеносный ответ, код и любые задачи).*
2. 🚀 **`qwen3:4b`** — *Очень быстрый и легкий (идеально для быстрого общения).*
3. ✨ **`gemma3:4b`** — *Отличный русский язык и сбалансированные ответы от Google.*
4. 🧠 **`qwen3:8b`** — *Умная сбалансированная модель с глубоким пониманием.*
5. 👑 **`deepseek-r1:8b`** — *Максимальный IQ для сложнейшей логики и анализа.*

## 🚀 Установка и Запуск

### Шаг 1. Установите Ollama
Для работы приложения требуется установленный сервер Ollama.
1. Скачайте и установите Ollama с официального сайта: **[ollama.com](https://ollama.com)**
2. Убедитесь, что она запущена (в трее появится иконка Ollama).

### Шаг 2. Скачайте необходимые модели
Откройте терминал (командную строку) и скачайте нужные вам модели (или сразу все):

```bash
ollama pull qwen2.5-coder:7b
ollama pull qwen3:4b
ollama pull gemma3:4b
ollama pull qwen3:8b
ollama pull deepseek-r1:8b
